# LaunchDarkly AI SDK for .NET

API reference for the LaunchDarkly AI SDK for .NET.

- `LaunchDarkly.AI.Server`: the core SDK.
- `LaunchDarkly.AI.Server.ExtensionsAI`: the `Microsoft.Extensions.AI` (`IChatClient`) provider.
- `LaunchDarkly.AI`: a convenience package that references `LaunchDarkly.AI.Server`. It has no API of its own.

This is a pre-1.0 working version and is not yet published to NuGet. See the [README](https://github.com/launchdarkly/dotnet-ai-sdk#readme) to build it from source.
